# 上游许可证与署名资料

本项目仅合并与去重，保留各上游的权利与许可，不为合并后的规则统一声明新许可。仓库账号代表维护来源，间接来源与原创作者仍以上游说明为准。

GitHub 许可文件按 API 返回的实际路径保存。独立官方站点保留其原始文件头署名与条件。未识别到许可证时明确列出，不推定为无版权。

Dan Pollock 的原始文件声明允许非商业复制和分发，并要求保留原始 URL 与署名；本项目在订阅文件头及下面的原文快照中保留这些信息。
