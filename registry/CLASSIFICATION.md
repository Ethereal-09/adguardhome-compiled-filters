入选条件：原始 GitHub 仓库 README 为中文，或上游明确说明 DNS 规则面向中国地区；证据见 sources.json 的 selectionEvidence 与 regionalFocus。不按账号、作者姓名、.cn 后缀或 IP 推断地区。

| 订阅 | 组成 | 用法 |
| --- | --- | --- |

秋风不采用包含“不受欢迎”规则的版本。国外通用源、服务整站限制组件、停止维护来源与不能安全转换的浏览器列表已移除。中文合集仍可能间接包含国外上游，完整作者与引用以原仓库为准。

精确去重在每个订阅内部完成，各订阅独立完整。覆盖优化只移除相同动作、相同优先级且匹配范围被已有规则覆盖的简单条目；精确子域不会扩大成父域规则。原生放行例外不丢弃。
